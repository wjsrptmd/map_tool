# 캐릭터 보행 애니메이션 코드 적용 프롬프트

주인공 캐릭터에 준비된 `idle` 및 `walk` 애니메이션이 실제 이동 상태와 방향에 맞게 재생되도록 C++ 코드를 수정해줘. 캐릭터 리소스와 JSON은 수정하지 않는다.

## 현재 리소스

- 정의: `projects/sample/characters/00000001/character.json`
- 프레임 크기: 64 x 64px
- `idle`: `down`, `up`, `left`, `right`, 각 1프레임
- `walk`: `down`, `up`, `left`, `right`, 각 4프레임, 8fps, 반복
- 스프라이트 시트 프레임은 가로로 배치됨

## 필요한 동작

1. 방향키를 누르면 캐릭터 방향을 `up`, `down`, `left`, `right` 중 해당 값으로 갱신한다.
2. 실제 이동 중에는 상태를 `walk`로 설정한다.
3. 이동이 멈추면 마지막 방향을 유지하면서 상태를 `idle`로 되돌린다.
4. `fps`와 `frames`에 따라 현재 프레임 인덱스를 시간 기반으로 계산한다.
5. 반복 애니메이션은 마지막 프레임 뒤 첫 프레임으로 돌아간다.
6. `fps: 0` 또는 `frames: 1`이면 항상 첫 프레임을 표시한다.
7. 상태나 방향이 바뀌면 애니메이션 시간을 처음부터 시작한다.
8. 스프라이트의 texture rect x 좌표를 `frameIndex * frameWidth`로 계산한다.
9. 기존 `anchor`, 카메라, 타일 이동, 이웃 맵 전환 규칙은 유지한다.
10. 이동이 막힌 경우에도 방향은 갱신하되, 실제 위치 변화가 없으면 `walk`를 계속 재생하지 않는다.

## 검증

- 네 방향으로 이동할 때 올바른 시트와 프레임 순서가 사용되어야 한다.
- 키를 놓으면 마지막 방향의 대기 이미지로 돌아가야 한다.
- 맵 경계를 넘은 뒤에도 방향과 애니메이션 상태가 정상이어야 한다.
- `--self-test`에서 상태·방향 전환과 프레임 인덱스 계산을 검사한다.
- 기존 맵과 캐릭터 리소스 검증도 계속 통과해야 한다.
