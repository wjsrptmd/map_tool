# map_tool 데이터 프롬프트

이 프로젝트는 맵을 만들고 확인하는 툴이다. C++ 네임스페이스는 `maptool`이다. JSON은 `nlohmann/json`으로 읽는다.

시작할 때 `config/start_config.json`의 `project` 값을 읽고, `projects/{project}/`를 연다. 지금은 `"project": "sample"`이라 `projects/sample/`이다. 프로젝트 이름은 폴더 한 단계만 허용한다. 영문, 숫자, `_`, `-`만 쓸 수 있다.

그 폴더에서 다음을 읽는다.

- `map_info.json`: 화면 설정과 타일 정의
- `world/y_x.map`: 월드 맵. 파일 이름의 `y`가 행, `x`가 열이다
- 타일 이미지: `map_info.json`의 `image`가 상대 경로면 프로젝트 폴더 기준이다

배틀 맵, 배틀 이벤트, 아군·적 배치는 없다. `kind`는 `world`만 허용한다.

## map_info.json

최상위 키는 `globalConfig`와 `tiles`뿐이다.

`globalConfig` 필드는 모두 필수다.

- `viewColumns`, `viewRows`: 화면에 보이는 칸 수. 양의 정수
- `tileSize`: 타일 한 칸의 픽셀 크기. 양수
- `marginX`, `marginY`: 창 여백 픽셀. 양수
- `framerate`: 초당 프레임. 양의 정수
- `windowTitle`: 창 제목. 빈 문자열 금지. 실제 창 제목은 `{windowTitle} - {프로젝트 이름}`
- `backgroundColor`: 창 배경색. `[r, g, b]`, 각 값은 0 이상 255 이하 정수
- `emptyTileColor`: 맵 밖이거나 이미지가 없는 칸의 색. 같은 RGB 형식

`tiles`는 배열이다. 각 원소는 객체이고 필드는 다음뿐이다.

- `id`: 숫자만으로 된 문자열. 예: `"00000001"`. 객체 키가 아니라 필드다. 앞의 0을 유지한다
- `name`: 타일 이름. 빈 문자열 금지
- `image`: 이미지 경로. 빈 문자열 금지. 상대 경로면 프로젝트 폴더 기준이며 파일이 있어야 한다
- `canEnter`: 그 칸으로 이동할 수 있는지. `true` 또는 `false`

같은 `id`는 한 번만 있을 수 있다. 맵 칸의 이동 가능 여부는 이 `canEnter`로 판단한다.

영웅 반지름 12와 영웅 색 `[214, 176, 132]`는 `map_info.json`에 없다. `main.cpp`에 있다.

## *.map

경로는 `projects/{project}/world/{y}_{x}.map`이다.

- 파일 이름 줄기는 `y_x` 하나뿐이다. 밑줄은 한 번만 있고, `y`와 `x`는 정수다
- 예: `0_0.map`은 y=0, x=0이다
- 같은 좌표 파일이 둘이면 오류다
- 좌표에 해당하는 파일이 있을 때만 그 월드 맵이 존재한다
- 파일은 y가 작은 순, 같으면 x가 작은 순으로 정렬한다. 시작 시 첫 맵을 연다

인코딩은 UTF-8이다. 맨 앞의 BOM은 무시한다. 헤더 줄의 앞뒤 공백과 탭, CR은 제거한다.

파일은 헤더, 구분 줄, 타일 줄 순서다.

```
kind-world
name-맵 이름
width-22
height-14
-
00000003-00000001-00000002
00000003-00000001-00000001
```

### 헤더

헤더의 각 줄은 `키-값`이다. 첫 번째 `-`만 키와 값을 나눈다. 값은 그 뒤 전체다.

필수 키는 `kind`, `name`, `width`, `height`다. 각각 한 번만 쓴다.

- `kind`: 값은 `world`만 가능하다
- `name`: 빈 문자열 금지
- `width`, `height`: 양의 정수. 아래 타일 줄의 열 수, 행 수와 같아야 한다

알 수 없는 키, 같은 키의 반복, `-`가 없는 줄은 오류다.

빈 줄, `;`로 시작하는 줄, `#`로 시작하는 줄은 헤더에서 무시한다.

`backgroundColor`와 `emptyTileColor`는 맵 파일이 아니라 `map_info.json`의 `globalConfig`에 있다.

### 타일 구분

헤더 다음에 `-`만 있는 줄이 온다. 이 줄부터 타일 영역이다.

### 타일 줄

한 줄이 맵의 한 행이다. 칸은 타일 `id`이고 `-`로 구분한다.

- 각 칸은 숫자만으로 된 id다. 예: `00000001`
- 빈 칸, 글자, 기호는 오류다
- 모든 행의 칸 수는 같아야 한다
- 행이 하나도 없거나 칸이 없는 행은 오류다
- 타일 영역의 빈 줄은 건너뛴다
- 줄 끝의 CR은 제거한다
- 각 id는 그 프로젝트 `map_info.json`의 `tiles`에 있어야 한다. 없는 id가 있으면 그 맵은 열리지 않는다

`width`는 한 행의 id 개수와 같고, `height`는 타일 줄 수와 같다. 헤더 숫자와 실제 칸 수가 다르면 오류다.

좌표는 왼쪽 위가 `(0, 0)`이다. x는 오른쪽, y는 아래다. 영웅은 코드에서 `(2, 7)`에 선다. 이 좌표는 맵 파일 필드가 아니다.

지금 샘플 월드 맵은 다음 세 장이다. 모두 가로 22, 세로 14다.

- `world/0_0.map`: 고요나무 숲
- `world/0_1.map`: 바람길
- `world/0_2.map`: 돌여울 마을

현재 타일 id는 다음과 같다.

- `00000001` 풀, 이동 가능
- `00000002` 길, 이동 가능
- `00000003` 나무, 이동 불가
- `00000004` 바위, 이동 불가
- `00000005` 물, 이동 불가
- `00000006` 집, 이동 불가
- `00000007` 막힘, 이동 불가
