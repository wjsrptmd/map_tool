# 48px 타일 적용 후 권장 코드 수정 프롬프트

이 프로젝트의 C++ 코드를 검토하고, 48px 타일 설정에서 캐릭터 크기가 기존 40px 기준과 같은 비율로 표시되도록 최소 범위로 수정해줘.

## 현재 설정

`projects/sample/maps/map_info.json`의 현재값은 다음과 같다.

- `tileSize`: 48
- `viewColumns`: 27
- `viewRows`: 15
- `marginX`, `marginY`: 각각 20
- 맵 표시 영역: 1296 x 720px
- 실제 창 크기: 1336 x 760px

화면 크기, 카메라, 타일 위치 및 스프라이트 배율은 이미 `map_info.json` 설정값을 사용한다. 해당 부분에는 48, 27, 15를 하드코딩하지 않는다.

## 권장 코드 변경

1. `src/Game.cpp`에서 캐릭터 원의 반지름을 하드코딩된 `12.f` 대신 타일 크기에 비례해 계산한다.
   - 40px 타일에서 반지름 12px였던 비율을 유지한다.
   - `characterRadius = config.tileSize * 0.3f` 형태로 계산한다.
   - 48px 타일에서는 반지름이 14.4px가 되어야 한다.
   - 캐릭터는 계속 현재 칸의 정중앙에 그려져야 한다.

2. 기존 40x40 타일 이미지를 48x48로 1.2배 확대하는 동안에는 현재의 `texture.setSmooth(true)`를 유지한다.
   - 비정수 배율에서 nearest-neighbor를 사용하면 픽셀 폭이 불균일해질 수 있으므로 이번 작업에서는 smoothing 정책을 바꾸지 않는다.
   - 나중에 모든 이미지가 네이티브 48x48로 교체되면 smoothing 비활성화를 별도 검토한다.

## 변경하지 않을 것

- `*.map` 파일과 타일 배치
- `map_info.json` 및 이미지 리소스
- 이동 가능 여부와 이웃 맵 전환 규칙
- 카메라의 기존 중심·경계 계산
- JSON 형식과 검증 규칙

## 검증

- `--self-test`가 성공해야 한다.
- 화면에는 27 x 15칸이 표시되어야 한다.
- 최종 창 크기는 1336 x 760px여야 한다.
- 캐릭터 반지름은 14.4px이며 현재 칸의 중앙에 있어야 한다.
- 3x3 큰 집과 2x2 큰 나무의 타일 조각 사이에 틈이나 어긋남이 없어야 한다.
