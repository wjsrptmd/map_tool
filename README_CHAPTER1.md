# 1장 테스트 버전 — 숲 밖의 식탁

## 실행

Visual Studio 2022에서 `game_prj.sln`을 열고 **Debug / x64** 또는 **Release / x64**로 실행합니다.
프로젝트 변경 알림이 나오면 다시 로드합니다. 시작 화면에서 **새 여행 시작**을 누릅니다.
게임은 모니터 크기에 맞춰 창을 만들며, 창 크기를 바꾸거나 최대화할 수 있습니다.

## 이번 버전의 범위

- 인간 남성 주인공 **루안**. 이름과 어머니 **세린**의 이름은 임시 설정입니다.
- 3개 탐험 지역: 고요나무 숲, 바람길, 돌여울 마을. 각 22×14칸입니다.
- 전투장 12×9칸에서 필수 전투 3개와 완료 전투 재도전.
- 선택 계약 동료 10명, 주인공 포함 최대 5명 출전.
- 한글 대화, 선택 영입 조건, 거점 편성, 공통 레벨 성장, 진행 수첩.
- 저장·불러오기, 패배 후 재도전·재편성, 1장 결말과 이후 자유 탐험.

진영 교대, 전투 전 편성, 전투 중 교체 없음, 영구 사망 없음은 **테스트용 제안 규칙**입니다.
스토리의 지역명과 적대 인물도 이번 플레이를 위한 초안입니다.

## 기본 조작

| 상황 | 조작 |
|---|---|
| 탐험 | 빈 땅·몬스터·주민·표식을 왼쪽 클릭 |
| 대화 | 버튼 클릭 또는 Space / Enter |
| 계약·전투 제안 거절 | 다음에 결정 버튼 / Esc |
| 거점·편성 | B 또는 화면 아래 버튼 |
| 여행 기록과 다음 목표 | J |
| 수동 저장 / 불러오기 | F5 / F9 |
| 탐험 격자 | G |
| 탐험에서 타이틀로 | Esc, 확인 후 저장하고 복귀 |
| 전투 중 철수·재편성 | Esc 또는 철수 버튼, 확인 후 복귀 |

탐험에서는 클릭한 대상까지 장애물을 피해 걸어갑니다. 이동 중에는 목적지 도착을 기다린 뒤 다음 명령을 내립니다.
표지판을 클릭하면 지역을 이동합니다. 주민과 몬스터는 **발밑 칸**을 클릭하면 됩니다.
전투 진입 시 동료가 부족하면 취소하고 거점에서 편성할 수 있습니다.

## 전투 조작과 규칙

1. 오른쪽 동료 목록 또는 전장 위 아군을 클릭해 선택합니다.
2. **1 이동**을 고른 뒤 초록색 이동 가능 칸을 클릭합니다.
3. **2 공격**을 고른 뒤 사거리 안의 적을 클릭합니다.
4. **3 기술**은 기술에 맞는 대상을 클릭합니다. 회복은 자신 또는 아군, 공격 기술은 적,
   보호막과 공격 강화는 시전자를 클릭합니다.
5. **4 방어**는 행동을 소모해 보호막 7을 얻습니다.
6. **5 물약**은 행동을 소모해 선택한 캐릭터의 체력을 24 회복합니다. 전투당 3개입니다.
7. **Space / 턴 종료**로 적 진영에 차례를 넘깁니다.

- 아군마다 이동 1회, 주요 행동 1회를 사용합니다. 공격 후 이동도 가능합니다.
- 나무·상자와 살아 있는 유닛은 이동을 막습니다. 대각선 이동은 없습니다.
- 사거리는 상하좌우 칸 수이며, 지형 장애물은 원거리 공격과 회복의 시야도 막습니다.
- MP는 전투마다 전부 회복합니다. 기술·물약·방어는 각각 주요 행동 1회를 사용합니다.
- 모든 아군이 전투 불능이 되면 패배합니다. 주인공이 쓰러져도 다른 동료로 계속 싸울 수 있습니다.
- 출전 인원에 맞춰 적 수가 바뀝니다. 특정 동료나 직업은 필수가 아닙니다.
- 10명의 동료는 전투 불능이나 대기 때문에 사라지지 않습니다.

영입은 모두 선택입니다. 조건을 해결해도 마지막 계약 버튼을 눌러야 동료가 됩니다.
처음 4명까지는 자동 출전하며 나머지는 대기합니다. B로 자유롭게 변경할 수 있습니다.

## 1장 진행 안내 — 아래는 사건 순서입니다

1. 숲의 어른과 대화하거나 자유롭게 주변을 탐험합니다. 숲의 동쪽 표지판으로 바람길에 갑니다.
2. 바람길 중앙의 **길목의 검문소**를 클릭해 첫 전투를 해결합니다.
3. 동쪽 표지판을 통해 마을에 들어가 북서쪽 **기록원 이안**과 대화합니다.
4. 마을 동쪽 **압수 수레**에서 두 번째 전투를 해결합니다.
5. 바람길로 돌아가 북동쪽 **제국 보급 창고**에서 세 번째 전투를 해결합니다.
6. 마을의 **기록원 이안**에게 장부를 전달하면 1장 결말에 도달합니다.

동료 없이도 이 순서로 완료할 수 있습니다. 결말 이후에는 남은 영입과 전투 재도전을 계속할 수 있습니다.
단서와 사건 해결은 동료의 개인사나 고유 능력에 의존하지 않습니다.

## 저장 위치

Visual Studio 프로젝트에서 실행하면 프로젝트 루트의 `saves/chapter1.sav`에 저장합니다.
Debug와 Release가 같은 파일을 사용합니다. 지역 이동·영입·주요 사건 해결 뒤 자동 저장합니다.
새 여행을 시작하면 이전 여행은 `chapter1.previous.sav`에 별도로 보관합니다.
전투 도중 저장은 지원하지 않으며, 재실행하면 전투 전 탐험 상태에서 재개합니다.
미리보기와 자동 검증은 실제 여행 저장을 사용하지 않습니다.

## 다음 튜닝에 사용할 파일

- `src/ChapterData.hpp`: 몬스터 10명의 능력치·기술·영입 조건과 목표 문구.
- `src/MapManger.hpp`, `src/MapManger.cpp`: 탐험·전투 맵 리소스, 지역명·이벤트·몬스터 배치·출전 위치, 통행·경로·시야 판정.
- `src/ChapterGame.cpp`: 이동, 전투, 대화, 영입, 저장, 화면 구성.
- `src/ChapterGame.hpp`: 진행 상태와 게임 구성.
- `src/main.cpp`: 창 생성과 입력, 시작점.

공통 레벨은 사건 첫 승리마다 오르며 대기 동료에게도 적용됩니다. 재전투는 레벨 보상을 반복하지 않습니다.
이번에는 프로젝트 하나로 구성했으며 별도의 범용 엔진 라이브러리나 편집기는 만들지 않았습니다.

## 검증 명령

`game_prj.exe --self-test <검증용 폴더>`

테스트는 지정한 폴더의 별도 저장을 사용합니다. 전체 이야기의 단독 완료, 10명 영입, 여러 편성의 승리,
기술과 이동·행동 제한, 선택 계약, 저장·불러오기 및 손상된 저장 거부를 확인합니다.

## 현재 제한

- 그림은 SFML 도형으로 그린 임시 그래픽이며 완성 일러스트·애니메이션·음원은 포함하지 않았습니다.
- 탐험 캐릭터는 걸어서 이동하고, 전투 이동은 즉시 칸을 변경합니다.
- 장비, 제작, 진화·전직, 전투 중 교체, 고저차는 구현하지 않았습니다.
- 한국어 표시는 현재 Windows에 설치된 맑은 고딕을 사용합니다. 폰트를 프로젝트에 복사하지 않았습니다.
- 2장 이후, Steam 연동과 배포 패키지 제작은 아직 포함되지 않았습니다.

먼저 전투 난이도, 클릭과 사거리의 이해도, 동료별 체감 차이, 대사의 길이를 함께 조정하면 좋습니다.
