character.json move 필드 설명
=============================

파일 위치
---------
resources/characters/{characterId}/character.json

자동 이동 설정은 character.json의 최상위 선택 필드인 move에 작성한다.
move 필드가 없는 캐릭터는 자동으로 움직이지 않는다.
move 설정은 같은 characterId를 사용하는 모든 NPC 인스턴스의 기본 이동 규칙으로 사용한다.
플레이어 캐릭터는 move 필드가 있더라도 자동 이동 대상으로 처리하지 않는다.


character.json 예시
------------------

{
  "id": "00000002",
  "name": "돌여울 서문지기",
  "defaultState": "idle",
  "defaultDirection": "down",
  "anchor": [32, 60],
  "collisionRadius": 14.4,
  "animations": {
    "idle": {},
    "walk": {}
  },
  "move": {
    "speed": 0.8,
    "route": [
      { "x": 0, "y": 0 },
      { "x": 1, "y": 0 },
      { "x": 2, "y": 0 },
      { "x": 1, "y": 0 }
    ],
    "loop": true
  }
}


move 공통 필드
--------------

speed
  자료형: 양수 실수
  단위: 초당 이동하는 타일 수
  의미: 값이 클수록 빠르게 이동한다.

  예시:
    0.5 = 2초마다 한 칸
    0.8 = 약 1.25초마다 한 칸
    1.0 = 1초마다 한 칸
    2.0 = 0.5초마다 한 칸

  애니메이션의 fps와는 별개의 값이다.


경로 이동 필드
--------------

route
  자료형: position 객체 배열
  의미: 캐릭터의 최초 배치 위치를 기준으로 한 상대 좌표 경로다.
  배열의 각 원소는 x와 y 정수 필드를 가진다.
  첫 원소는 반드시 { "x": 0, "y": 0 }이어야 한다.
  서로 인접한 원소는 상하좌우 한 칸 차이여야 한다.

  최초 배치 위치가 (5, 7)이고 상대 경로가 (0,0), (1,0), (2,0)이면
  실제 이동 위치는 (5,7), (6,7), (7,7)이 된다.

loop
  자료형: boolean
  route를 사용하는 경우에만 사용한다.
  true이면 마지막 경로 위치 다음에 첫 위치로 돌아가 반복한다.
  false이면 마지막 위치에서 이동을 종료하고 idle 상태가 된다.
  loop가 true이면 마지막 route 원소와 첫 원소도 상하좌우 한 칸 차이여야 한다.


무작위 이동 필드
----------------

radius
  자료형: 0 이상의 정수
  의미: 최초 배치 위치에서 벗어날 수 있는 최대 맨해튼 거리다.
  route 대신 radius를 사용하면 범위 안에서 상하좌우 무작위 이동을 한다.

  radius가 3이면 최초 위치로부터 |dx| + |dy| <= 3인 위치에서만 이동한다.


형식 규칙
---------

1. move는 character.json의 선택 필드다.
2. move가 없으면 자동 이동하지 않는다.
3. type 필드는 사용하지 않는다.
4. intervalMs 필드는 사용하지 않는다.
5. idleChance 필드는 현재 사용하지 않는다.
6. route와 radius 중 정확히 하나만 있어야 한다.
7. route와 radius를 동시에 사용할 수 없다.
8. route를 사용하면 loop가 반드시 있어야 한다.
9. radius를 사용하면 loop를 사용하지 않는다.
10. x와 y는 픽셀이 아니라 타일 기준 상대 좌표다.
11. 자동 이동 NPC는 다른 맵으로 넘어가지 않는다.
12. 목적지가 막힌 타일이거나 다른 충돌 캐릭터가 있으면 해당 이동을 취소하고 다음 이동 시점에 다시 시도한다.
13. 실행 중 변경된 위치와 경로 순서는 character.json에 다시 기록하지 않는다.


경로 이동 예시
--------------

"move": {
  "speed": 0.8,
  "route": [
    { "x": 0, "y": 0 },
    { "x": 1, "y": 0 },
    { "x": 2, "y": 0 },
    { "x": 1, "y": 0 }
  ],
  "loop": true
}


무작위 이동 예시
----------------

"move": {
  "speed": 0.7,
  "radius": 3
}
